# Temperature measurement review - synthetic demo

This authored example tests document retrieval. It is not a manufacturer manual.

## Sensor plausibility

This synthetic review compares temperature channels TS1, TS2, TS3, and TS4.
Review missing values, abrupt changes, and whether channels change together.
An unexpected reading in one sensor motivates a measurement-quality review.
It does not establish that the sensor is defective.

## Reference and operating conditions

Compare complete temperature cycles with a reference from supported, stable
operating conditions. Changes in operating conditions can affect the comparison.
For this demo, report differences in cycle mean temperature in degrees Celsius.
An anomaly score describes a statistical deviation, not a failure probability.
